## 산출물은 착수 시점에 정의한다

알람·장애 조사의 기본 산출물은 4칸이며, **원인 확정은 조치를 정당화하는 근거일 뿐 산출물 자체가 아니다.**

1. 장애 여부
2. 실제 서비스 영향
3. 재발 조건 (임계 근접 여부 포함)
4. 조치 항목

원인 규명이 '확정 불가'로 끝나도 아래를 반드시 낸다. **"원인이 아님" 판정을 받았다는 이유로 여기서 빼지 않는다.**

- 기여 요인 / 개선 여지 — 실측 수치 + 제안 조치(인덱스, 트랜잭션 분할, 실행 시각 이동)
- 계측·모니터링 격차 — 어떤 권한·지표·보존 설정이 있었으면 답할 수 있었는지
- 재발 조건 — 다음에 언제 다시 울릴 것인가

## 조사 노트 형식 — 열린 질문 대장

문서 최상단에 **살아있는 표**를 둔다: `가설 / 상태 / 근거 / 반례 / 재검토 조건 / 열린 질문`.
라운드가 끝날 때마다 **신규 확정 사실 × 열린 질문**을 교차한다. 새로 확정한 사실이 기존 열린 질문의 답인지 매번 확인한다.

## 정지 규칙

한 라운드가 **새로운 후보 유형을 0개** 산출하면 조사를 종료하고 현재 상태로 보고한다.
(위 규칙들이 전부 조사를 길게 만들므로 이 상쇄 장치가 없으면 규칙 세트 전체가 순손실이 된다.)
